# M-Dance Website Implementation Guide

## Getting Started

This guide will help you implement the M-Dance website. Follow these steps to set up the project correctly.

### 1. Project Setup

Create a new React project:

```bash
npx create-react-app mdance-website
cd mdance-website
```

### 2. Install Dependencies

Install required dependencies:

```bash
npm install react-router-dom
```

### 3. Directory Structure Setup

Create the directory structure as outlined in the file organization:

```bash
# Inside the project root
mkdir -p src/components src/pages src/assets public/images/trainers public/images/certifications public/images/gallery public/images/achievements
```

### 4. File Creation

Copy all the provided files to their respective locations according to the file structure.

### 5. Assets Preparation

1. Add your logo file as `src/assets/logo.png`
2. Add your banner video as `src/assets/banner-video.mp4`
3. Add trainer photos to `public/images/trainers/`
4. Add certification images to `public/images/certifications/`
5. Add gallery images to `public/images/gallery/`
6. Add achievement images to `public/images/achievements/`

### 6. YouTube Video Integration

Update the `YouTubeVideos.jsx` component with your actual YouTube video IDs:

```javascript
// In src/components/YouTubeVideos.jsx
const videos = [
  'YOUR_ACTUAL_VIDEO_ID_1',
  'YOUR_ACTUAL_VIDEO_ID_2',
  'YOUR_ACTUAL_VIDEO_ID_3'
];
```

### 7. Test and Run

Start the development server and verify all components are working:

```bash
npm start
```

### 8. Production Build

When ready for production:

```bash
npm run build
```

The production-ready files will be in the `build` directory.

## Important Notes

1. **Responsive Design**: The website is designed to be fully responsive. Test on various device sizes.

2. **Browser Compatibility**: Test the site in different browsers (Chrome, Firefox, Safari, Edge).

3. **Image Optimization**: Compress all images for optimal loading speed.

4. **Banner Video**: Ensure the banner video is compressed and optimized for web.

5. **Font Awesome**: The site uses Font Awesome icons, which are loaded from a CDN in `index.html`.

6. **Google Fonts**: The site uses Montserrat font, which is loaded from Google Fonts in `index.html`.

## Customization Options

### Colors

Main color scheme can be adjusted in CSS files:

- Primary Pink: `#ff7bac` (M-Dance brand color)
- Text Dark: `#333`
- Text Medium: `#444`
- Text Light: `#666`
- Background Light: `#f9f9f9`
- Background White: `#ffffff`

### Layout

Section padding and container widths can be adjusted in the CSS files:

- `.container` max-width: `1200px`
- Section padding: `80px 0` (desktop) and `60px 0` (mobile)

## SEO Considerations

Update the meta tags in `public/index.html` with appropriate descriptions for better SEO.
